# TNBIM – ESCT Nantes

Application du module « La transition numérique, le BIM et les enjeux juridiques » (Manager de projets BTP, ESCT Nantes) : chantier fictif commun, projet de groupe parmi quatre, journal de bord IA, grille de soutenance.

Page publiée : https://pierrickbriand.github.io/tnbim-esct/

Une seule page HTML, sans serveur. Le travail des étudiants reste dans leur navigateur et dans leur fichier de projet (.json).

Sources dans `src/`. Assemblage : `python3 src/build.py` depuis la racine du dépôt.
